# Petite Grace v0.2.0 — Advanced Reader

## Included

- PDF.js-based continuous PDF reader with selectable text layers
- Single-column and two-up continuous scrolling
- Virtualized page rendering for long documents
- Fit-width, fit-page and custom zoom
- Full-text search and page jump
- Reading-layout, zoom and page progress persistence
- Offline PPTX subset renderer with positioned text and images
- Explicit compatibility warnings for unsupported charts, tables, SmartArt, animations and advanced layout
- PPTX single/double-column reading and progress persistence

## Verification

- Unit/integration tests: 12 passed
- Playwright fixture E2E: 2 passed
- Virtualization check: fewer than 12 canvases rendered for a 30-page fixture
- Production userscript build: passed
- Production dependency license inventory: passed
- Real Xiaoya platform acceptance: **NOT VERIFIED**

## Known limitations

- PPTX is a best-effort subset and not a full Microsoft Office rendering engine.
- PDF text selection is enabled, while persistent annotations arrive in v0.3.0.
- Live Xiaoya API and long-document performance still require logged-in platform verification.
