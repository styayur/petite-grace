# Petite Grace v0.5.0-rc.2

This compatibility release candidate addresses four P0 defects identified in a real authenticated Xiaoya course view.

## Fixed

- Chapter ordering now supports platform order, natural chapter-number order and local overrides.
- Mixed Chinese/Arabic chapter numbering and decimal sections sort naturally while unnumbered chapters retain their relative positions.
- Resource titles are multiline, expandable, keyboard accessible and touch friendly.
- Left/right pane widths can be resized and are persisted locally.
- Encrypted `is_encryption` resource URLs are decrypted and validated.
- Signed CDN URLs are fetched without Xiaoya credentials; same-origin credentials remain restricted to platform endpoints.
- Preview-only resources can be previewed even when download is not permitted.
- CORS-blocked authorized resources can use a scoped anonymous `GM_xmlhttpRequest` adapter.
- PDF loading now supports cancellation, safe redirect validation, size limits and expired-link errors.
- Video resources open in an in-app HTML5/HLS reader with speed, fullscreen, PiP, resume position and platform-player fallback.

## Verification

- Unit/integration tests: 45 passed
- Playwright E2E: 8 passed, screenshot capture skipped by default
- Security audit: 0 vulnerabilities
- Fixture evidence covers encrypted URLs, signed CDN hosts, rejected origins, expired links, preview-only access, CORS fallback, PDF search/selection/annotation/state, ordering, long titles, pane resizing and video initialization.

## Release gate

This remains a **Pre-release**. Live Xiaoya acceptance is `NOT_VERIFIED` because Windows Computer Use could not determine the active Chrome URL with sufficient confidence, so the authenticated page could not be safely inspected. No cookie, token, signed URL or personal data is included in this release.
