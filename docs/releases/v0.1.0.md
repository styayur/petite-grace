# Petite Grace v0.1.0 — Foundation

This pre-release establishes the first installable userscript and the full-screen course workspace.

## Included

- TypeScript/Vite/Preact architecture with a single-file userscript build
- Fluent 2-inspired light and dark tokens
- Shadow DOM UI isolation
- Xiaoya course detection, session-scoped API adapter, and normalized course model
- Chapter tree and resource list with explicit-order/fallback evidence
- Basic PDF, image, PPTX metadata, and resource-download flows
- Bounded concurrent download queue with cancel/retry/progress
- Local course cache and settings through IndexedDB
- Governance, privacy/security policies, CI, E2E, security, and release workflows

## Verification

- Unit/integration tests: passed
- Playwright fixture E2E: passed

## Known limitations

- The PDF reader is still the browser-native preview in this version.
- PPTX rendering and annotation/review/AI features arrive in later releases.
- The live API shape may differ from the open-source reference adapters and must be verified against a logged-in account.
