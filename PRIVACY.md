# Privacy Policy

Petite Grace is local-first.

- Course metadata, reading positions, annotations, review items, provider settings, and AI response caches are stored in the browser by default.
- The platform session token is read transiently only to call the platform's same-origin APIs. It is never written to logs, IndexedDB, exports, or analytics.
- API keys are stored locally in IndexedDB. They are excluded from normal data export. Users can delete them from Settings or clear all local data.
- No course content is sent to a third party unless the user explicitly enables an AI provider and initiates a request.
- AI requests contain only the current question or the smallest explicitly selected excerpt. They do not contain platform cookies, session tokens, grades, or the whole course by default.
- The app does not use a third-party document preview service and does not upload private course files by default.
- The project does not include telemetry, advertising, or background data contribution.
