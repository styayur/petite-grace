# ADR 0005: Review and Release Gates

Status: accepted

## Review scheduler

Use a documented SM-2-style scheduler:

- Again: reset repetitions, record a lapse, return in 10 minutes
- Hard: reduce ease, schedule at least one day
- Good: first interval 1 day, second 3 days, then previous interval × ease
- Easy: increase ease and use a longer interval

All schedule fields are stored locally. The review UI is a single focused card, with Space to reveal and 1–4 for feedback.

## Release gate

Automated status is generated by `npm run acceptance`, which executes typecheck, unit/integration tests, Playwright, security audit, license inventory and production build. The acceptance JSON records actual command outcomes.

A Stable release additionally requires a verified real Xiaoya acceptance record. If that record is `NOT_VERIFIED`, the release gate stays `blocked` and the workflow publishes a Pre-release only.
