# Petite Grace v0.4.0 — Exercises & Free AI

## Included

- Exercise HTML/DOM parsing with typed question and option models
- Per-question navigation, viewed/completed/needs-review status
- Local answer draft and status persistence
- Platform-verified reference answers kept distinct from AI inference
- Free-first Provider Registry for Groq, OpenRouter, Gemini and OpenAI-compatible endpoints
- API Key and model configuration in local IndexedDB
- Model discovery and local response caching
- Explicit per-question consent before external transmission
- Hint, step-by-step explanation and answer-check modes
- Provider failure fallback and clear error classification
- Save exercise explanations or answers as local review items

## Verification

- Unit and integration tests: 26 passed
- Playwright fixture E2E: 4 passed
- No-API-key path leaves reading, exercise status and review creation usable

## Known limitations

- AI answers are never presented as platform-verified answers.
