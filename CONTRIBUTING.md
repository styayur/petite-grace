# Contributing

Open an issue or a pull request. GitHub runs this repository's existing checks on the pull request.

- External pull requests are not auto-merged. A maintainer reviews and merges them with the normal GitHub controls.
- Updates from the repository owner, and Dependabot patch or minor updates, can auto-merge after the required checks pass.
- Dependabot major updates stay open until someone verifies compatibility.
- Changes to workflows, Actions permissions, or signing material are not auto-merged.
- A failed, skipped, cancelled, or missing required check keeps the pull request open.

No model review, special approval command, or external service is required to understand or complete that path.
Maintainer merges use GitHubs normal squash merge after the checks above are green.
