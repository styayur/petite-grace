# Petite Grace v0.3.0 — Annotations & Reading State

## Included

- Select PDF text and create yellow, blue, green, or pink highlights
- Page-relative highlight rectangles that survive zoom changes
- Short note editing for each highlight
- Concentrated annotation list in the collapsible right panel
- Click-to-locate annotations in the PDF reader
- Annotation JSON import and export
- IndexedDB persistence for annotations and reading state
- Quote-based relocation checks and an explicit “needs relocation” state
- Basic focus-reading mode that hides both side panels

## Verification

- Unit and integration tests: 20 passed
- Playwright fixture E2E: 3 passed
- Annotation note restored after page reload
- Highlight remains visible after switching zoom mode
- Real Xiaoya platform acceptance: **NOT VERIFIED**

## Known limitations

- Automatic re-anchoring updates the page when a quote is found, but does not recompute exact highlight rectangles for a materially changed source file.
- Annotations currently target PDF documents; PPTX annotation anchoring is not part of this release.
