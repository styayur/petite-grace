# Changelog

All notable changes are recorded here. The project follows semantic versioning for release tags.

## [0.5.0-rc.1] - 2026-11-10

### Added

- Anki-style review card workspace with due/today counts
- SM-2-style review scheduler and local review progress
- Review creation from exercises, highlights and notes
- Review JSON import/export and source navigation
- Reflowable reader text size/line-height settings
- Keyboard shortcuts and narrow-viewport responsive coverage
- Test-derived acceptance script and release-channel gate

## [0.4.0] - 2026-11-10

### Added

- Exercise parser, question navigation and local completion/review status
- Platform-answer versus AI-inference separation
- Groq, OpenRouter, Gemini and OpenAI-compatible Provider Registry
- Local API Key/model settings, discovery, caching, rate limiting and fallback
- Per-question AI consent, hint, explanation and answer-check modes
- Review-item creation from exercises
- AI provider and paid-model guardrail tests

## [0.3.0] - 2026-11-10

### Added

- PDF text highlighting with page-relative anchors
- Editable short notes and a concentrated annotation panel
- Annotation import/export and click-to-locate navigation
- Quote-based annotation relocation and explicit missing-quote state
- Focus-reading mode
- IndexedDB integration tests for reading state and annotations

## [0.2.0] - 2026-11-10

### Added

- PDF.js continuous reader with single-column and two-up layouts
- Virtualized PDF page rendering, text layer, search, zoom and page jump
- Reading progress and layout persistence
- Offline PPTX subset parser and reader for text, basic shapes and images
- Compatibility warnings for unsupported presentation content

## [0.1.0] - 2026-11-10

### Added

- Initial installable userscript and Shadow DOM workspace
- Xiaoya course adapter with stable chapter/resource mapping
- Resource download queue with progress, cancel and bounded concurrency
- Local course cache, Fluent-inspired themes and governance/CI foundation

## [Unreleased]

### Added

- Initial project governance, privacy boundaries, and release rules.
