# Petite Grace v0.5.0-rc.1

This release candidate completes the planned functionality pending real-platform acceptance.

## Included

- Anki-style focused review cards with Space reveal and 1–4 ratings
- SM-2-style scheduling with Again/Hard/Good/Easy intervals
- Review creation from exercises, highlights and notes
- Local review progress, due counts and JSON import/export
- Return from a review card to its original resource/annotation
- Reflowable text size and line-height settings for exercises, AI output and review cards
- Keyboard shortcuts: `F` focus mode, `R` review, `Esc` close
- Responsive narrow-viewport and dark-theme behavior
- Automated acceptance script that records real command outcomes
- Full regression coverage for ordering, reading state, annotations, exercises and review

## Verification

Verification is generated by `npm run acceptance` and recorded in the release's `acceptance-0.5.0-rc.1.json`. The record includes typecheck, unit/integration, Playwright, dependency security, license inventory and build status.

## Release gate

This is a **Release Candidate**, not Stable. The automated suites pass, but the live Xiaoya platform path remains `NOT_VERIFIED` because the logged-in browser-control path was unavailable. The release workflow must publish this version as a Pre-release.
